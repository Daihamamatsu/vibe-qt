## 1. 概要

タートル・トレーディング方式は、トレンドフォロー戦略として知られる手法です。本リポジトリではその核となる **Donchian Channel ブレイクアウト** と **ATR (N)** をフロントエンド機能として実装しています。

| ファイル | 役割 |
|---|---|
| `stock-app/frontend/src/utils/turtle.ts` | 計算モジュール（純粋 TS、Vue 非依存） |
| `stock-app/frontend/src/components/Stock.vue` | チャート UI（ECharts）＋入力パネル |
| `stock-app/frontend/src/utils/turtle.test.ts` | ユニットテスト（vitest） |

- **バックエンド / DB は変更なし**。すべての計算はブラウザ内で行われます。
- 戦略のルールは「価格が**過去 N 日間の高値圏をブレイクしたら買い（BUY）、安値圏を割り込んだら売り（EXIT）**」で、ATR を用いてポジションサイズとストップを決めます。

## 2. 計算ロジック

| 項目 | 定義 | チャート上 |
|---|---|---|
| **Donchian Upper (DC20 / エントリーライン)** | 前日までの 20 日間の最高値（当日は除外） | 橙色の破線 |
| **Donchian Lower (DC10 / 手仕舞いライン)** | 前日までの 10 日間の最安値（当日は除外） | 青色の破線 |
| **N (ATR)** | True Range の Wilder 平滑化（14 / 20 選択可、既定 20） | 紫色ライン（下部サブパネル） |
| **BUY** | 当日終値 > DC20（上抜け） | 赤い上向き三角マーカー（当日ローソク足の高値より上側に表示） |
| **EXIT** | 当日終値 < DC10（下抜け）、**または** 当日終値 ≤ トレーリングストップ | 緑の下向き三角マーカー（当日ローソク足の安値より下側に表示） |

### 数式

- True Range: `TR = max(high - low, |high - 前日終値|, |low - 前日終値|)`
- ATR (N): TR の Wilder 平滑化（初期値 = 最初の N 日間の TR の単純平均、以降 `ATR = (前 ATR × (N−1) + 当日 TR) ÷ N`。データ不足の期間は `null`）
- トレーリングストップ: 直近 10 日高値 − 2 × N（いずれも前日終了時点）
- 1 ユニット推奨株数: `floor(口座資金 × 0.01 / N)`（株式は 1 ポイントあたり価値 = 1 固定のため買値は掛けない）
- ピラミッディング目標: 直前ユニットの目標ライン + 0.5N（P2 基準 = 買値、到達後は到達時の価格でライン固定。N が一定なら 買値 + {0.5, 1.0, 1.5}N と一致）、ストップロス: 最新エントリーの目標ライン −2N（買い増し到達で引き上げ。買い増し未到達時は 買値 −2N）
- 買い増し計画: ブレイク日以降、**直前ユニットの目標ライン + 0.5 × 当日のN** で目標ラインを毎日更新（P2 基準 = 買値、到達後は到達時の価格でライン固定）、終値が目標ラインに到達 (≥) した日に買い増し（同日の複数レベル到達を許容）
- 計画 EXIT: 終値 ≤ `最新エントリーの目標ライン − 2 × N`（買い増し到達で引き上げ、買い増し未到達時は `買値 − 2 × N`）の日、または終値 < DC10 の日の初回到達（同日に両方該当すればストップを優先）

### 設計ポイント

- **ルックアヘッド・バイアス回避**: バンド（DC20/DC10）とシグナル判定は**前日までのデータのみ**を使用（当日のローソク足は範囲からシフト除外）。当日の価格が自分のラインを作る参照になることはありません。
- データが揃うまでの間はバンドが `null` となり描画されません（DC20 は 20 日、DC10 は 10 日、ATR は N 日が必要）。
- `open/high/low` が null のレコードは `close` にフォールバックします。
- BUY と EXIT が同日に同時に立つことはありません（ユニットテストで保証済み）。

## 3. 使い方（UI 操作手順）

1. **データを取得する**: 「株価データ」パネルでシンボル（例: `AAPL`）・期間（1y 以上推奨）を指定して **取得**（DB）または **Yahoo Finance から取得** を押す。
   - ブレイクアウト判定は履歴が必要なため、**1 年以上（できれば 2y〜5y）** を取得するのが望ましい（DC20 は 20 日分の履歴、ATR は N 日分の履歴が必要）。
2. **「タートル戦略」パネル**（チャート下）:
   - **表示** チェック: チャートへのオーバーレイを ON/OFF（既定 ON）。ON 時はチャートが 3 段グリッド（高さ 640px）になります。
   - **ATR 期間 N**: `14` / `20`（既定 20 = クラシック・タートル）。
   - **口座資金**: ユニット算出に使う資金（例: `1000000`）。
   - **ブレイク日**: BUY シグナルが出た日のみ候補になる下拉リスト。既定は最新の BUY 日。手動選択した場合は次回取得でも上書きされません（シンボル変更でリセット）。
   - **買値**: データ取得時に最新終値が自動設定されます。ブレイク日を選択するとその日終値へ自動設定されます（手動入力は上書きしない）。手動入力した場合は次回取得でも上書きされません（シンボル変更でリセット）。
3. **情報パネル**の表に「直近 N (ATR)」「1 ユニット推奨株数」「ピラミッド目標 / ストップ」が自動表示されます。
4. **買い増し / EXIT 計画**（ブレイク日が指定されている場合、情報パネルの表に追加表示）:
   - **買い増し計画 (P2/P3/P4)**: 各レベルについて到達日・目標価格・到達日終値（未到達の場合は「未到達」）。
   - **EXIT 計画**: 到達日・理由（ストップロス / DC10 下抜け）・終値（未到達の場合は「未到達」）。
   - **チャート上のマーカー**: 買い増し到達日に◇（紫）、計画 EXIT 日に■（緑）が表示されます（既存の BUY/EXIT シグナルマーカーとは別物）。

## 4. チャートの見方

タートル表示 ON 時は、チャートが 3 段グリッドになります:

```
┌─────────────────────────────┐
│ 上段: ローソク足             │ ← DC20 / DC10 破線 + BUY/EXIT マーカー + ピラミッド目標ライン
├─────────────────────────────┤
│ 中段: 出来高バー             │
├─────────────────────────────┤
│ 下段: N (ATR) ライン         │ ← ボラティリティ（ATR が大きいほど値動きが荒い）
└─────────────────────────────┘
```

### 各要素の意味

- **橙色の破線 DC20**: この線を**終値が上抜けした日 = BUY**（赤 ▲、当日ローソク足の高値より上側に表示）。トレンド転換・ブレイクアウトのサイン。
- **青色の破線 DC10**: この線を**終値が下回った日 = EXIT**（緑 ▼、当日ローソク足の安値より下側に表示）。
- **トレーリングストップ**: 直近 10 日高値から 2N を引いた位置に終値が到達した日も EXIT（DC10 とは別経路の手仕舞い）。
- **紫色の ATR ライン**: 値動きの幅の平均（ボラティリティ）。ATR が大きい = 値動きが荒い = ストップ幅（2N）も広い、という関係です。
- **紫の水平破線**: `ピラミッド2 (+0.5N)` / `ピラミッド3 (+1.0N)` / `ピラミッド4 (+1.5N)` — 上昇中の買い増し目安価格。
- **赤い水平破線**: `ストップ (-2N)` — 買値からの最大損失ライン。
- **◇ 紫マーカー (買い増し2/3/4)**: ブレイク日以降、終値が `直前ユニットの目標ライン + 0.5 × N`（毎日その日の N で再計算 / 到達後は到達時の価格でライン固定）に到達した日（計画）。
- **■ 緑マーカー (計画 EXIT)**: 終値 ≤ `最新エントリーの目標ライン − 2N`（買い増し到達で引き上げ、買い増し未到達時は `買値 − 2N`）、または終値 < DC10 の初回到達日（計画）。既存の BUY/EXIT シグナルマーカーとは別物。
- **カラー**: 日本式（陽線=赤、陰線=緑）。BUY = 赤 / EXIT = 緑。
- **tooltip**: カーソルを乗せると OHLC（`[open, close, low, high]` 表示）と出来高（K/M 表記）が出ます。
- **ズーム / パン**: Ctrl+ホイール = ズーム、通常ホイール = パン、ドラッグ = パン、下部スライダーで可視範囲を直接指定。

### 読み方のポイント

1. **DC20 と DC10 の間が「中立帯」**です。価格がその幅の中に収まっている間は新規判断なし、が基本の読み方です。
2. **BUY 後に価格が +0.5N / +1.0N / +1.5N の目標に届くたびに 1 ユニットずつ買い増し**（ピラミッディング）、逆に **−2N では全量で損切り**するのがクラシックな運用です。
3. ATR が膨らむ局面では**推奨株数が自動的に減る**（1 ユニットのリスク = 口座資金の 1%）ため、ボラティリティが高いときに無理に大きくなりません。
4. 表示ローソク足の本数が 20 本（または N 日）未満ではバンド / ATR は描画されず（「ATR を計算するには N 日以上のデータが必要です」ヒント表示）。データ取得時は十分長い期間を指定してください。

## 5. ポジションサイジングとピラミッディング

| 概念 | ルール |
|---|---|
| 1 ユニット | `floor(口座資金 × 0.01 / N)` 株（株式は 1 ポイント = 1 固定のため買値は掛けない） |
| ピラミッド 2 | 買値 + 0.5N（= 直前ユニットの目標ライン + 0.5N）に到達 → 1 ユニット追加 |
| ピラミッド 3 | 直前ユニットの目標ライン + 0.5N（N 一定なら 買値 + 1.0N）に到達 → 1 ユニット追加 |
| ピラミッド 4 | 直前ユニットの目標ライン + 0.5N（N 一定なら 買値 + 1.5N）に到達 → 1 ユニット追加 |
| ストップ | 最新エントリーの目標ライン − 2N（買い増し到達で引き上げ、買い増し未到達時は 買値 − 2N）→ 全ポジション手仕舞い |

### 機械的計画（買い増し / EXIT、Issue #44）

ブレイク日（BUY シグナル日）が指定されると、買い増しと EXIT を機械的にシミュレートします。

1. **買い増し (P2/P3/P4)**: ブレイク日以降、**毎日その日の N** を使って **直前ユニットの目標ライン + 0.5 × N** で目標ラインを更新（P2 基準 = 初回買値。到達したレベルの目標ラインは**到達時の価格で固定**され、次レベルの基準となる）。終値が目標ラインに到達 (≥) した日に買い増しが発生します（同日の複数レベル到達を許容）。
2. **EXIT**: 終値 ≤ `最新エントリーの目標ライン − 2 × N`（ストップロス。買い増し P2/P3/P4 の到達に伴い 0.5N ずつ引き上げられ、買い増し未到達時は `買値 − 2 × N`）、または終値 < DC10（手仕舞いライン下抜け）の**初回到達日**で計画終了します。
3. 計画は指標シグナル（BUY/EXIT マーカー）とは独立した**計画表**であり、実際の売買記録ではありません。

## 8. 注意点

- パラメータ（ATR 期間 / 口座資金 / 買値）の変更で `computed` 経由の**自動再描画**が行われるため、リロードは不要です。
- BUY / EXIT は**終値基準の参考シグナル**です。実取引ではスリッページ・約定価格に注意してください。
- 本戦略は**トレンドフォロー型**のため、レンジ相場では連続ストップ（もみ合いでの切り売り）になりやすい点に留意してください。
- 本ドキュメントは学習・参考用であり、投資助言を目的とするものではありません。
